# Security policy

Please do not report a security problem in a public issue.

## How to report

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository,
then **Report a vulnerability**. Only the maintainer sees the report.

If you cannot use it, write to `11footy.game@gmail.com`.

Please include what you found, how to reproduce it, and the version or commit you used.

## What happens next

- We reply within 7 days.
- We fix confirmed problems as soon as we can and publish an advisory when the fix is out.
- We credit you in the advisory if you want to be credited.

## Scope

In scope: the Vesta code, the desktop window, the launchers, and the checks of a downloaded
dataset (`SHA256SUMS` and its signature).

Out of scope: wrong or missing football data. Open an issue in the 11footy-dataset repository
for that.
